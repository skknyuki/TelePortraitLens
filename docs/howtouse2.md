# How to Use2

## 特殊な撮影テクニック

* [M]-[Optics] でForeとBackの画角を **それぞれ** 変更できます。
* [M]-[Fore]・[Main]・[Back]で、３つのカメラの設定をそれぞれ変更できます。  
設定は、WorldFixによりカメラをそれぞれ別の場所へ置いたり  
[Color Correction]内で背景を暗くしたり  
前景のコントラストを上げたりする事もできます。  

* [M]-[Fore]-[LayerBlend]で前景の絵をPhotoshopのようなレイヤーブレンドを選べます。  
前景の絵をスクリーン合成したり、乗算合成したりできます。

---

## できることの例

- 背景カメラだけを別方向に向けて、実際には存在しない構図を作る
- 前景だけを Screen / Multiply で合成して、光・水面・花・影などを重ねる
- Fore / Main / Back それぞれに別の色補正をかける
- 被写体だけを明るくし、背景だけを暗くしてポートレート感を強める
